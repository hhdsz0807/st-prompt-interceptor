## 🌟 核心特性 (Key Features)

### 📱 0. 手机端/触屏极致适配 (Mobile & Touch Friendly) [v1.1.0 新增]
- **全自由手势拖拽**：悬浮球支持多端触屏与鼠标手势拖拽，智能边缘吸附与视口防出界保护，位置自动记忆持久化（`localStorage`）。
- **一键重置防遮挡**：设置面板内新增 **【🎯 悬浮球重置到屏幕安全位置】** 按钮，无论被软键盘或输入栏如何挤压，随时一键归位。
- **魔棒扩展菜单直达**：无缝注入 SillyTavern 顶部 **魔棒扩展菜单 (`#extensionsMenu`)**，手机上关闭悬浮球也能随时打开。
- **移动端自适应双视图**：手机窄屏下自动启用响应式布局，顶部提供 **【📜 提示词正文】** 与 **【📑 消息层级目录】** 选项卡切换，在目录中选中楼层后自动无缝切回正文阅读。
- **零阻塞即时唤起**：未发包时点击悬浮球不再静默拦截，而是提供友好就绪指引与一键伪装注入入口。


### 🛑 1. 毫秒级硬拦截阻断 (Zero-Token Hard Interceptor)
- **真·零 Token 消耗**：在点击发送消息到发往大模型的最后一瞬间，双重锁（API 拦截 + Fetch 网络层守卫）瞬间切断发包流程。
- **杜绝空跑与计费**：大模型收不到任何请求，网络请求完全不外发，调试提示词、世界书命中与记忆召回无需消耗任何 API 额度。
- **随时放行**：拦截后可在面板中直接点击 **`[放行发送给 AI]`** 恢复本次请求。

### 📖 2. 左右分栏纯净大滚动条 (Master-Detail Split-Pane Reader)
- **告别卡片堆叠与拥挤**：彻底推翻传统几十个折叠卡片挤占一页的糟糕体验，重构为专业级的**左右分栏架构**。
- **独立大滚动条 (Scrollbar)**：右侧阅读区独享一整页全高平滑滚动条，上万字的长提示词像看电子书一样顺滑滚动到底。
- **消息层级聚焦**：左侧罗列所有消息层级（`System 预设/世界书/记忆`、`User 历史对话`、`Assistant AI 历史`、`User 最新输入`、`原始 Payload JSON`），既可全局合并阅读，也可单层深度聚焦。
- **舒适排版**：高对比度纯黑底白字排版，默认 16px 大号字体，支持 `小`、`标准`、`大` 字号无缝切换与关键字高亮搜索。

### 🎭 3. 伪装注入 AI 回复并触发各插件 (Mock AI Reply Injection)
- **外部回答无缝回流**：用户可将网页端（Claude、ChatGPT、DeepSeek、Kimi 等）或本地大模型生成的回答复制进来，一键伪装注入酒馆。
- **全要素原生装配**：自动提取当前角色的头像、名字、Swipe 滑动槽与时间戳，完美融入酒馆楼层。
- **完整生命周期事件广播**：自动触发酒馆原生三大核心事件：
  - `MESSAGE_RECEIVED`
  - `CHARACTER_MESSAGE_RENDERED`
  - `GENERATION_ENDED`
- **激活全生态第三方插件**：
  - ✅ **角色编年史 (Tavern Character Chronicle)**：自动捕获剧情并触发记忆蒸馏
  - ✅ **世界书动态雷达 (Worldbook Radar)**：自动对回复进行词条扫描与动态匹配
  - ✅ **TTS 语音合成**：正常检测到新回复并触发语音朗读
  - ✅ **Live2D / 角色表情包 / 状态栏**：正常感知响应并切换角色状态

## 📦 安装方法 (Installation)

### 方式一：通过酒馆扩展安装器 (推荐)
1. 打开 SillyTavern，点击右上角 **扩展管理图标 (积木图标)**。
2. 找到 **“安装扩展 (Install Extension)”**。
3. 在扩展 Git 仓库 URL 输入框中粘贴：
   ```text
   https://github.com/hhdsz0807/st-prompt-interceptor
   ```
4. 点击 **保存 / 安装**，等待安装完成并刷新浏览器 (`F5`)。

### 方式二：手动 Git Clone
进入 SillyTavern 的第三方扩展目录执行克隆：
```bash
cd SillyTavern/public/scripts/extensions/third-party
git clone https://github.com/hhdsz0807/st-prompt-interceptor.git
```
重启或刷新酒馆页面即可。

## 🎮 使用指南 (Quick Start)

### 1. 截留透视最终发包
1. 在酒馆右侧“扩展设置”面板展开 **【最终提示词截留透视器】**。
2. 确保勾选 **`🛑 开启发包截留阻断`**（默认开启）。
3. 像往常一样在聊天框输入消息并发送：
   - 消息将在发送前被截留，AI 不会收到任何请求。
   - 屏幕将自动弹出 **“最终发往 AI 的完整提示词截获报文”** 面板。
4. 在右侧大滚动区完整审查拼接完毕的全部系统设定、世界书词条与召回记忆。
5. 点击右上角 **`[复制 JSON]`** 或 **`[复制本页文本]`** 即可带到外部网页大模型中使用。

### 2. 伪装注入外部 AI 回复
1. 在外部（例如网页端 Claude 或 DeepSeek）获得满意的 AI 回答后复制文本。
2. 打开截留面板顶部的 **`[ 🎭 伪装注入 AI 回复 ]`** 抽屉（或在酒馆扩展设置面板点击 **`🎭 快速伪装注入 AI 最新回复`**）。
3. 粘贴回复内容，点击 **`[ 确认伪装为 AI 回复并注入酒馆 ]`**。
4. 回复立即以当前角色的身份渲染进酒馆楼层，并自动激活角色编年史、世界书雷达等所有插件！

## ⚙️ 设置项说明 (Settings)

| 设置项 | 默认值 | 作用说明 |
| :--- | :---: | :--- |
| **开启发包截留阻断** | `开` | 勾选后发送消息会被截断，不发给 AI，零 Token 消耗并自动弹窗透视；关闭后变为纯透视放行模式。 |
| **启用插件** | `开` | 控制插件总开关。 |
| **控制台打印完整 Payload** | `开` | 在浏览器 F12 Console 展开输出完整的发包 JSON 报文。 |
| **在屏幕上显示常驻可拖拽悬浮球** | `开` | 在屏幕上提供高层级（999999）悬浮徽标，支持手势拖拽与实时拦截状态呼吸灯。 |
| **🎯 悬浮球重置到屏幕安全位置** | 按钮 | 一键将悬浮球恢复到屏幕右上侧安全可视区域，防止被手机软键盘或底部输入框遮挡。 |
